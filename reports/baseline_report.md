## Measured failure and fix: blind boundary guessing

Policy `boundary_guess` (auditenv/policies/boundary_guess.py) reads the tables and flags the 6 documents closest to a period boundary as period_cutoff, without any reconciliation. 20 cutoff-heavy episodes (4 cutoff errors, other errors 0), closed mode:

| generator | boundary_per_cutoff | return (mean) | episodes with return > 0 | P (mean) | TP / FP |
|---|---|---|---|---|---|
| before fix | 0 | 0.100 | 15/20 | 0.467 | 56 / 64 |
| after fix | 2 | -0.401 | 3/20 | 0.258 | 31 / 89 |

Cause: cutoff errors were built with the same boundary documents as the 2-5 boundary distractors, so with 4 errors a blind guess had about 50% precision. Fix: 2 extra boundary distractors per cutoff error (config `distractors.boundary_per_cutoff`, default 2). Re-check: tests/test_redteam.py test_blind_boundary_guessing_is_not_profitable_on_cutoff_heavy_books.
